🔑Acesso

Como funciona o acesso

A senha é validada no servidor (Vercel) — o token do GitHub fica guardado lá como variável de ambiente e nunca chega ao navegador. Sem a senha, a página funciona em modo somente leitura.

Configuração (uma vez só, pelo dono do projeto):

  1. Vercel → projeto simulador-kard → Settings → Environment Variables
  2. Adicione GITHUB_TOKEN = token fine-grained com Contents: Read and write no repositório
  3. Adicione ADMIN_PASSWORD = a senha que a equipe vai usar aqui
  4. Deployments → ⋯ → Redeploy para aplicar

Para trocar a senha depois, basta editar ADMIN_PASSWORD na Vercel e redeployar.
