🔑Acesso

Como gerar o token (uma vez só)
  1. Acesse github.com/settings/personal-access-tokens/new (logado como dono do repositório ou colaborador)
  2. Token name: simulador-admin · Expiration: 1 ano (ou o que preferir)
  3. Repository access: Only select repositories → simulador-kard
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token e cole aqui. O token fica salvo somente neste navegador.

Sem token, a página funciona em modo somente leitura. Cada pessoa que for editar precisa do seu próprio token (ou ser colaborador do repositório com um token próprio).
